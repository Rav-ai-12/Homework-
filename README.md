# הבית שלנו 🏡

אפליקציה לניהול משימות הבית של אלעד, רביד, אדם, אור ואלמה. מתקינים אותה על אייפון ועל אנדרואיד דרך "הוספה למסך הבית" (PWA), והיא מופיעה עם אייקון הבית.

## מה יש בתיקייה

| קובץ | מה הוא עושה |
|---|---|
| `index.html` | האפליקציה עצמה |
| `firebase-config.js` | הפרטים של Firebase (ממלאים פעם אחת) |
| `manifest.webmanifest`, `sw.js`, `icons/` | מה שהופך את האתר לאפליקציה שאפשר להתקין |
| `firestore.rules` | כללי האבטחה של מסד הנתונים |
| `artifact/index.html` | הגרסה הישנה שרצה בתוך claude.ai |

## הגדרה חד-פעמית (בערך 15 דקות)

### שלב 1: פתיחת Firebase (חינם)

1. נכנסים ל-https://console.firebase.google.com ומתחברים עם חשבון גוגל.
2. **Create a project**. השם יכול להיות `bayit-shelanu`. את Google Analytics אפשר לכבות.
3. בתפריט הצד: **Build ← Authentication ← Get started**. בלשונית **Sign-in method** בוחרים **Anonymous** ומפעילים (**Enable**).
4. בתפריט הצד: **Build ← Firestore Database ← Create database**.
   - מיקום: `eur3 (europe-west)`.
   - בוחרים **Start in production mode**.
5. ב-Firestore עוברים ללשונית **Rules**, מוחקים את מה שכתוב שם, מדביקים את התוכן של הקובץ `firestore.rules` ולוחצים **Publish**.
6. לוחצים על גלגל השיניים ליד **Project Overview ← Project settings**. למטה, תחת **Your apps**, לוחצים על הסמל `</>` (Web).
   - נותנים כינוי (למשל `bayit`). **לא** צריך לסמן Firebase Hosting.
   - מופיע קוד עם `const firebaseConfig = { apiKey: ..., ... }`. **מעתיקים את הקוד הזה ושולחים לClaude**, או מדביקים את הערכים לבד בקובץ `firebase-config.js`.

> הערכים האלה לא סודיים, ומותר שיופיעו בקוד. ההגנה על הנתונים מגיעה מכללי האבטחה ומהמזהה הסודי `FAMILY_ID` שכבר נמצא בקובץ.

### שלב 2: פרסום האתר ב-GitHub Pages (חינם)

1. במאגר ב-GitHub נכנסים ל-**Settings ← Pages**.
2. תחת **Build and deployment ← Source** בוחרים **Deploy from a branch**.
3. בוחרים את הענף שבו נמצאים הקבצים (`main` אחרי מיזוג, או `claude/family-chores-app-bqvdc8`) ואת התיקייה `/ (root)`, ולוחצים **Save**.
4. אחרי דקה-שתיים תופיע שם כתובת כמו `https://<שם-משתמש>.github.io/Homework-/`.

> ב-GitHub החינמי, Pages עובד רק כשהמאגר **ציבורי**. הקוד עצמו לא כולל שום מידע פרטי. הנתונים של המשפחה נשמרים ב-Firebase.

### שלב 3: התקנה בטלפונים

**אייפון (ספארי):** פותחים את הכתובת ← כפתור השיתוף ⬆︎ ← **הוספה למסך הבית** ← **הוסף**.

**אנדרואיד (כרום):** פותחים את הכתובת ← מופיע באנר "להתקין את הבית שלנו" ← **התקנה**. אם הבאנר לא מופיע: תפריט ⋮ ← **התקנת אפליקציה** או **הוספה למסך הבית**.

שולחים את הכתובת לכל בני המשפחה. כולם רואים את אותן משימות ואותם סימונים בזמן אמת.

## איך הנתונים נשמרים

- `families/<FAMILY_ID>/tasks/<id>`: הגדרת משימה. `slots[]` מכיל לכל פעם את `day` (0 עד 6, או `null` למשימה שעושים מתי שנוח השבוע), `label`, `assignee` (או `null` למשימה פתוחה) ו-`pool`. אפשר גם `rotation {pool, anchor}` לסבב שבועי.
- `families/<FAMILY_ID>/done/<week>_<task>_<slot>`: סימון ביצוע, עם `week`, `month` (החודש שבו השבוע מסתיים), `by`, `day` ו-`at`.
- בפתיחה הראשונה האפליקציה יוצרת לבד את ארבע משימות ההתחלה: מדיח, כביסה, סידור חדר וטאטוא מדרגות.

**ניקוד:** כל משימה שילד ביצע שווה כוכב. בסוף החודש מי שצבר הכי הרבה כוכבים בוחר גלידה או פיצה, ויכולים להיות כמה זוכים.
