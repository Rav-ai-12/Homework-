# הבית שלנו – ניהול משימות הבית

אפליקציית ווב (קובץ יחיד `index.html`) לחלוקת משימות הבית בין אלעד, רביד, אדם, אור ואלמה.
הדף רץ כ-Artifact ב-claude.ai ושומר משימות וסימונים במסד הנתונים המשותף של ה-Artifact (`claude.use("db")`).

- `tasks/<id>` – הגדרת משימה: `title`, `icon`, `order`, `slots[]` (`day` 0–6 או `null` = מתי שנוח השבוע, `label`, `assignee` או `null` = פתוח, `pool`), ואופציונלית `rotation {pool, anchor}` לסבב שבועי.
- `done/<week>_<task>_<slot>` – סימון ביצוע: `week`, `month` (חודש שבו השבוע מסתיים), `by`, `day`, `at`.

ניקוד: כל משימה שילד ביצע שווה כוכב אחד. בסוף החודש, מי שצבר הכי הרבה כוכבים בוחר/ת גלידה או פיצה (יכולים להיות כמה זוכים).
